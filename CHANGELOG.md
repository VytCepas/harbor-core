# Changelog

All notable changes to this project are documented in this file.

The format is Keep a Changelog.
Harbor is deployed from `main` and cuts no tagged releases, so there is no version heading to keep: the
record of a change is its merged pull request (`git log --merges`), and a tagged release, if one is ever
cut, gets a `## [<version>]` heading here first (`bin/ci-release-names.sh` holds the pair).
