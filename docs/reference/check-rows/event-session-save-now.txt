watches: **the audit line of a save-now nudge** (harbor#1044): the preset that runs `session-save-now.sh` on `session.save-now`. The nudge itself is the Stop hook's one `additionalContext` (ctx_pct at or above 90, or 75 right after a commit or PR, handoff older than the last milestone), sent only while this rule is installed, once per trigger, never when `stop_hook_active` is true
schedule: **not scheduled: a rule of `event.dispatch`, on by deploy** (`#default` in `contracts/event-rules.tsv`; `event-dispatch.sh reconcile` installs it, harbor#1437). It fires on `session.save-now`, debounced 300 s, at most 6 an hour. On: `harbor event on --preset event.session-save-now`. Off: `harbor event on --off event.session-save-now`; falsifier: `sh tests/session/state/stop.test.sh`
notifies: the session, as one continued turn asking for the handoff; a line in `reactions.log`
red: the model was asked to write the handoff and did not, or nudges repeat (a once-per-trigger fault). Disable: `harbor event on --off event.session-save-now` (the hook stops nudging at once)
