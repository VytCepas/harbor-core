watches: every literal that still names a repo at its **pre-move** address (`~/<repo>`, `$HOME/<repo>`, or the absolute home form) now that the repos live under `PORT_ROOT` (default `~/port`): harbor's tracked files, every other repo under `PORT_ROOT` (**derived from the directory**, sibling `<repo>-wt-*` worktrees excluded), the config dir's `bin/` and `skills/`, its installed `CLAUDE.md` (judged by `policy/constitution.md`'s exemption rows) and top-level `MEMORY/*.md` (never `MEMORY/WORK/` or `USAGE/`, which are session logs), settings, `~/.claude.json`, `fleet.yaml`, LaunchAgents plists, `~/.local/bin` symlinks, git worktree pointers and venvs. Each hit is CODE, DOC or EXEMPT; exemptions are per line, each with the operator's reason, in `contracts/port-paths-exempt.tsv`, and in the private layer's `port-paths-exempt.tsv` for the rows that quote a client's directory
schedule: **not scheduled — on demand: `sh bin/lint-port-paths.sh --verify` in the harbor checkout**; it is also the gate `remove-bridges.sh` (harbor#619 phase C) runs before it deletes a bridge. `sh bin/lint-port-paths.sh` alone prints the full TSV inventory; falsifier: `sh tests/lint/port-paths/port-paths.test.sh`
notifies: the terminal of whoever runs it: log-lib lines on stdout (contracts/logging.md): `note: CODE=n DOC=n EXEMPT=n (stale: n)`, a `WARN` and its fix per stale row, a `FAIL` and its fix when a CODE row remains, the summary `port-paths: N ok, M failed, K warnings`, exit 1. DOC rows are the harbor#629 list and are dispositioned there
red: CODE>0: a script, config, plist, symlink, worktree pointer or venv names an address that resolves only through a `~/<repo>` bridge, and breaks the moment phase C deletes it; `remove-bridges.sh` then restores `.claude.json` and removes nothing. A `**Path root:**` line in markdown is CODE (harbor#653): `drift-reference-check.sh` REF-5 resolves every `./` citation against it, so a pre-move root in the installed `CLAUDE.md` is every citation dead; it clears when `policy-constitution-install.sh` ships the current `policy/constitution.md`. A `NO CHECKOUT`, `NO READABLE CHECKOUT` or `NO REPO` row means it could not look, and is red on purpose; exit 3 means the scan itself died (D-29 unchecked) and is never a green; 2 is a bad argument. DOC is not red: prose that reads wrong and breaks nothing. `stale: n` means an exemption's line is gone, so delete that row. Disable: first repoint or retire `remove-bridges.sh`, which calls this as its gate, then delete this row, `bin/lint-port-paths.sh`, `tests/lint/port-paths/port-paths.test.sh`, `contracts/port-paths-exempt.tsv` and their lines in `contracts/suites.txt`, `contracts/suite-paths.txt` and `contracts/idle-tools.txt`
