watches: a subagent's SubagentStop payload (harbor#445 item E): its final message hashes the same as that agent's previous stop (duplicate report), or a `background_tasks` entry still `running` or `pending` has its launch receipt (`with ID: <id>`) in the agent's own transcript and is not the agent itself (a background job it started and did not stop). The array is parent-scoped, so a task with no receipt there stays silent
schedule: **not scheduled.** It runs at every SubagentStop, by `hooks/session-subagent-check/session-subagent-check.sh`, wired by `runtime-install`; falsifier: `sh tests/session/subagent/check.test.sh` (red with the script absent; mutation: inverting the hash compare, dropping the transcript match or the status filter, or removing the sentinel each reddens at least one assertion)
notifies: operator `systemMessage` stamped `[check:session.subagent-stop]`; none on a clean stop. Advisory: exit 0 on every path, never blocks, no `checks.log` line
red: a subagent reported twice, or left its own background work running. Not a verdict: a retried report may legitimately repeat. Disable: `touch ~/.claude/subagent-stop.off` (survives reinstall; `runtime-install` keeps wiring the hook, which then exits at once) or `SUBAGENT_STOP_CHECK=off`
