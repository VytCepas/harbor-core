watches: every directory directly under `PORT_ROOT` that is neither a registered repo (`bin/scope-roots.sh --repos`, the private `repos.tsv`; a directory a `roots.tsv` REPOS row names; the first segment of a nested path) nor an exempt kind (dot-directories such as `.worktrees`, `harbor-private`, `history`, and `<registered id>-wt-<x>` sibling worktrees). Files are not judged (harbor#966)
schedule: **not scheduled — on demand: `sh bin/drift-port-root.sh` in the harbor checkout** (`--names` prints just the names); falsifier: `sh tests/drift/port-root/port-root.test.sh`
notifies: the terminal of whoever runs it: one `FAIL` per directory with its modified date and a `fix:` line, summary `drift-port-root: N ok, M failed, K warnings`, exit 1. The findings are for the operator, who registers, archives or deletes each one; a re-run lists only what is still there
red: a directory sits in the workspace that no registry row accounts for: an unregistered repo, a stale clone or a scratch folder. Exit 2 means the registry or workspace could not be read (a refused `repos.tsv`, no `PORT_ROOT`), never a clean pass. Disable: delete this row, `bin/drift-port-root.sh`, `tests/drift/port-root/port-root.test.sh` and their lines in `contracts/suites.txt`, `contracts/suite-paths.txt` and `contracts/idle-tools.txt`
