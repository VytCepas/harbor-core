watches: **an unattended night of merges and deploys across the opted-in fleet** (harbor#1060, harbor#1018; ship contract v1 §5), by `bin/deploy-fleet.sh` (`harbor ship night`, and `harbor ship deploy` when approve calls it): each repo carrying `.agents/ship.config` on its default branch (its trusted state in the guarded `~/.claude/.helm-ship/`), its `ship:auto` PRs merged through `merge-stack` when green and unprotected, and the default branch's change since the last deployed commit planned (every manifest command bounded by a timeout), applied and verified; a red verify or a failed apply restores this run's snapshot and stops the night. [docs/design/deploy-fleet.md](docs/design/deploy-fleet.md)
schedule: **not scheduled**: a night session or the operator runs it; a schedule needs the operator's yes. Falsifier: `sh tests/ci/deploy-fleet/rollback.test.sh` (a red verify restores, files the receipt red and stops the night; each rail has a mutant) and the other three suites in `tests/ci/deploy-fleet/`
notifies: (1) the morning report `~/Deliverables/<date>-ship/REPORT.md`: merged, deployed, rolled back, skipped red, and queued with each approve command, the delta of that run only. (2) one `[check:deploy.fleet]` line per run in `~/.claude/cache/checks.log`. (3) its receipt `~/.claude/cache/checks/ship.json`, red over `<owner/name>:<stage>`, which `lint-findings.sh reconcile` files as finding `check/deploy.fleet`. (4) each queued approval goes through `gate-queue.sh`, whose `approval.open` the statusline shows as `⧗N`
red: a deploy was rolled back (or could not be restored), a plan or a merge failed, or a checkout could not be deployed from: read the report's Rolled back and Problems lines, fix the repo, then `approve deploy`. While a rollback is under 16 hours old no unattended merge or deploy runs and the receipt stays red. `stood-down` is the kill switch. **Disable:** `touch ~/.claude/.harbor-autoship.off` (every unattended merge and deploy refuses; remove the file to re-enable)
