watches: **what a finished session left behind** (harbor#1044): the preset that runs `session-cleanup-report.sh` on `session.state`, acting on done only: orphan processes naming the session's directory, and merged clean linked worktrees. **Report only: it kills and removes nothing**
schedule: **not scheduled: a rule of `event.dispatch`, on by deploy** (`#default` in `contracts/event-rules.tsv`; `event-dispatch.sh reconcile` installs it, harbor#1437). It fires on `session.state`, debounced 60 s, at most 12 an hour. On: `harbor event on --preset event.session-cleanup-report`. Off: `harbor event on --off event.session-cleanup-report`; falsifier: `sh tests/session/react/presets.test.sh`
notifies: `~/.local/state/harbor/sessions/<session_id>.cleanup.txt` and a `reactions.log` line
red: the report lists processes or worktrees; acting on them is the operator's. Disable: `harbor event on --off event.session-cleanup-report`
