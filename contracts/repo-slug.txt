# repo-slug.txt (harbor#1149) - the owner/name of the repository this harbor is: one line, below.
#
# WHO READS IT. A tool that names harbor's own repository (main-tip-verdict, runner-switch, gh-plan, ci-governor, ci-verified and
# findings-run) asks log-lib's repo_slug. In a checkout the answer is that checkout's own origin, so a clone under another
# owner needs no edit. An INSTALL has no checkout beside it: runtime-install ships this file as bin/repo-slug.txt, and that is the
# answer there. A checkout whose origin is not on github.com (a tarball, a local mirror) takes this line too.
#
# WHY A FILE AND NOT THE REGISTERED CHECKOUT. lint-findings-run.sh fetches whatever this names and runs it with the operator's gh login,
# so the name may not come from anything a session can write: the ~/port checkout's git config and the private layer both
# are. A deploy writes bin/, and only an operator runs a deploy (review #895).
#
# A COPY UNDER ANOTHER OWNER sets the line to its own name. Nothing else in the tree spells it.
