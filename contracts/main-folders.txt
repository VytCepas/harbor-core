# main-folders.txt (harbor#1442, #1440) — the folders an agent must never change through the file tools, because they
# hold the operator's own files or code that runs later outside the confinement. One path per line, home-relative
# (`~/`), each under a comment saying why. scope-managed-folders.sh renders each row as `Edit(<path>/**)` into the
# root-owned managed-settings.json's permissions.deny: Edit, not Write, because `Edit(path)` is the rule the harness
# consults for every file-editing tool (bin/admission-deny.sh, the NO `Write(<path>)` ENTRIES note). Bash does not need
# these rows: Seatbelt already limits it to the write zone in contracts/confinement-paths.txt. The private layer's
# main-folders.txt is read after this one (contracts/private-layer.md).
