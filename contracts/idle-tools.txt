# IDLE TOOLS (harbor#466) — every bin/ script that nothing runs, and why.
#
# WHY THIS FILE EXISTS. `bin/drift-reference-check.sh` was built 2026-08-03 for a real
# defect, was correct about what it watched, and NOTHING EVER RAN IT — no hook,
# no plist, no CI job, only a line in docs/how-to/handover.md naming a command a human types.
# Nobody typed it. It sat there for 34 days reporting a surface it had never
# looked at, and the reason nobody noticed is that "nothing runs this" was not a
# state anything could observe.
#
# docs/reference/checks.md registers what is SCHEDULED. This registers the complement: built,
# asserting something, wired to nothing. Lint rule C8 checks BOTH directions —
# a tool that quietly loses its last caller must appear here, and a line for a
# tool that has since GAINED one is a stale entry nobody can see is dead.
#
# FORMAT: one line per tool — `<script.sh>  <KIND>  <why>` — where KIND is one of
#
#   VERB      an operator types it, by hand or through `harbor <verb>`. A verb
#             nobody typed today is not a defect. It is here so that the day it
#             stops working, the failure has a name and an owner.
#   IDLE      it asserts something about the box and no schedule points it at
#             the box. This is the #466 backlog and it is meant to trend DOWN.
#             Every line here is a check waiting for a caller or a deletion.
#
# The KIND is for a human; C8 only reads the first field. Blank lines and lines
# beginning with `#` are ignored.
#
# WHAT C8 CAN AND CANNOT SEE, so a reader can judge a line rather than trust it:
# it counts a call as the script's basename in COMMAND POSITION on a non-comment
# line of CI, a plist, a hook, an inject pack, or another non-test script — plus
# a BARE mention inside another script, because an installer payload list and a
# `for h in …` wiring check are both wirings and neither is an invocation. The
# two operator surfaces are read too: the dispatcher `bin/harbor` (a `VERBS` row
# is a wiring) and the `justfile` (a recipe naming a bin/ path is a call), so a
# verb or recipe that reaches a tool IS a caller and its line here goes stale
# (harbor#474). A script naming itself does not count. A TEST calling a tool does not count
# either, and that exclusion is the whole point: CI proving an instrument works
# while nothing points it at the real subject IS the defect this registers.
