# Contributing

**Issues are welcome. Pull requests are not merged yet.**

This repository is an export. Each commit is a snapshot of the core of a private
development repository, written by `harbor deploy push`. Nothing flows back from
here yet, so a pull request would be overwritten by the next snapshot.

- **A bug or a gap:** open an issue with the command, what you expected and what
  happened.
- **A guard bypass or any other security finding:** follow `SECURITY.md`, not a
  public issue.
- **References like `harbor#N` or `(#N)`** point at the private development
  tracker. They record where a rule came from; you cannot open them.

This changes when the first outside contribution needs a way back.
