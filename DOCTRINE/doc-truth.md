# Doc-truth — the incidents behind "derive, don't state"

**On-demand.** The rules are in [CONSTITUTION.md](../CONSTITUTION.md) § *Fix the
system, not your notes*. This is why they exist. Moved out of the resident
prompt on 2026-07-26 alongside the other expansions.

**Load when:** adding a fact to a document, or wondering why `STATUS.md` is
generated.

## The sweep that produced the rule

On 2026-07-26 a sweep found **the same fact stated three different ways across
three documents**, and one file (`QA-PLAN.md`) contradicting
itself between two of its own sections. None of it was wrong when written. That
is the whole hazard: a copied fact drifts silently *while still reading
correctly*, so nothing looks broken until someone acts on the wrong copy.

## The mechanism

`STATUS.md` is generated by `bin/status-gen.sh` and is the only
place Harbor states a number about itself.

- **T1** fails when `STATUS.md` is stale.
- **T2** fails when another document restates one of its counts.
- **T3** fails when any document cites a repo path that does not resolve
  (generalising **K1**, which does it for the constitution alone).
- **T4** fails when a document names a `VytCepas/*` repo that does not exist.
- **T6** fails when a not-taken list names a skill sitting in `vendor/skills/`.
- **T7** fails when a document cites an external URL that was never verified.
- **T8** fails when an upstream hook has no disposition in `COVERAGE.md`.

Every one of those rules was added *after* an instance of the class shipped.

## Two deliberate exemptions

`FLOOR.md`'s pass tables and `QA-PLAN.md`'s measurements are **dated records**,
not claims about the present. Their numbers are the evidence this project's
conclusions rest on, and freezing them is the point.

## "A rule with no mechanism is a wish"

Harbor learned this the expensive way. [CONTRACTS/README.md](../CONTRACTS/README.md)
once described a *"CI freshness check"* that did not exist, and a suite claimed
to run in CI within ten minutes of the claim being written — and it did not.
Both have lint rules behind them now.

The same failure at a larger scale: a 186-capability coverage sweep wrote its
findings into a **commit message** and nowhere else, so two days later the
answer to "is the backlog recorded?" was no. That produced
[COVERAGE.md](../COVERAGE.md) and rule T8.

## Which layer owns which kind of fix

Moved out of `CONSTITUTION.md` on 2026-08-08. It is a map, not an obligation —
the rule ("encode the fix where it structurally lives") stays in the
constitution; the lookup table is reference and belongs here, where it can grow
without being paid for in every session's prefix.

| The thing | Where it lives |
|---|---|
| A convention agents must follow | the repo's `CLAUDE.md` / `AGENTS.md` |
| Something that must be *enforced* | `bin/lint-conventions.sh`, a CI job, a pre-commit hook |
| A guard's behaviour | the guard, plus a pinned assertion in its suite |
| A cross-repo seam | `CONTRACTS/` + a shared fixture both sides run |
| A durable fact about the world | the work-log / memory |

`STATUS.md` is **generated** and is the only place Harbor states a number about
itself; a document that wants to quote a count links to it. Lint rules
**T1/T2/T3** enforce that.
