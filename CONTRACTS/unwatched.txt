# UNWATCHED (harbor#594) — every property of this repo whose failure is on record
# and that NOTHING watches today, and what a watcher would have to assert.
#
# WHY THIS FILE EXISTS. A coverage sweep ran once before, on 2026-07-26, found 73
# gaps, and wrote them into a commit message (ea65713), where nobody looked. The
# sweep of 2026-09-22 asked one question of every recorded incident: which
# mechanism would catch a recurrence TODAY, and does it exist? Its answers are in
# COVERAGE-INCIDENTS.tsv, one row per incident, with the evidence. This file is
# the complement CHECKS.md cannot show: CHECKS.md registers what runs, and
# CONTRACTS/idle-tools.txt what is built and runs on nothing. This registers the
# properties that have no watcher at all.
#
# FORMAT: one line per property — `<slug>  <KIND>  <what a watcher must assert>`.
# The incidents behind a slug are the rows of COVERAGE-INCIDENTS.tsv whose
# `unwatched` column names it, and are not repeated here. KIND is one of
#
#   UNWATCHED  a machine could assert it and nothing does. This is the backlog,
#              and it is meant to trend DOWN: a line leaves when its watcher
#              exists and has been watched fail (CONSTITUTION §2.10).
#   REVIEW     a judgement no mechanism can make (which design to pick, when to
#              act on evidence). Only review watches it. Declared so the gap is
#              visible, not so it is closed.
#
# THE COUNT IS DERIVED, never stated: `awk '!/^#/ && $2=="UNWATCHED"' CONTRACTS/unwatched.txt | wc -l`,
# and STATUS.md carries it, so its history is the trend.
#
# SCOPE, so nobody reads it as more than it is: the sweep covered every issue
# labelled `bug` or `tech-debt` (open and closed), DEAD-ENDS.md and both HANDOFF
# files. Incidents recorded only in PR threads, commit messages or other repos
# were not swept, and an incident nobody recorded cannot appear here.
